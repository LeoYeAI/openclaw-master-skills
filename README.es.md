## 🤖 Impulsado por [MyClaw.ai](https://myclaw.ai)

**[MyClaw.ai](https://myclaw.ai)** es una plataforma de asistente IA con servidores dedicados para cada usuario. Agent Master Skills es nuestra colección curada, actualizada semanalmente, con las mejores skills del ecosistema.

> 🌐 **Prueba MyClaw.ai**: [https://myclaw.ai](https://myclaw.ai)

## 🚀 Instalación

```bash
clawhub install agent-master-skills
# o
git clone https://github.com/LeoYeAI/agent-master-skills.git
cp -r agent-master-skills/skills/<skill-name> ~/.openclaw/workspace/skills/
```


> Todos los harness compatibles y sus carpetas: ver la tabla en [README.md](README.md#-how-to-install).
